## Player internal-detail correction

The original automated verdict was `FAIL`; the independent review verdict is `PASS`.

Component status rows are expected for authorized players. With
`health.player-details=false`, only the parenthetical `ComponentHealth.detail` text is
suppressed. The evidence image shows status rows such as `Config: UP` without parenthetical
internal details. The original failure was therefore a test-interpretation error, not a product
failure.

The behavior is fixed to the release source by these references:

- [`HealthCommandHandler.java`](https://github.com/eariver/Project-Wayfarer-Plugins/blob/192cda35dce0dba855c2da4eb1ed71a0425f549a/plugins/wayfarer-core/src/main/java/io/github/eariver/wayfarer/core/command/HealthCommandHandler.java)
- [`HealthCommandHandlerTest.java`](https://github.com/eariver/Project-Wayfarer-Plugins/blob/192cda35dce0dba855c2da4eb1ed71a0425f549a/plugins/wayfarer-core/src/test/java/io/github/eariver/wayfarer/core/command/HealthCommandHandlerTest.java)
