client acceptance failed because provider-absent `WayfarerServices.transactions()` threw
synchronously while the transaction command created its `CompletionStage`, outside the existing
asynchronous failure handler.

stage creation behind one command-boundary helper. A focused regression covers synchronous
service lookup failure for both paths, preserves the existing asynchronous failure behavior, and
asserts sanitized output and warning text. The focused test and local `check` passed. No
Transaction Engine, repository, migration, provider contract, Project Runtime, or external plugin
was changed.

This PASS does not set traceability to `CLEARED`, release readiness to `READY`, or
`requirements_cleared=true`. Concrete Waymark authority and Project placement/acceptance remain
