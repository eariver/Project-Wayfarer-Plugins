## Known limitation

Vault `SUCCESS` proves only that the common Vault/RedisEconomy route accepted the operation. It
does not prove durable Redis completion, provider transaction-record completion, atomic operation
identity, effect lookup, or exactly-once. Concrete `resolve` therefore remains `UNKNOWN`; Core does
not infer an effect from balance and does not automatically repeat UNKNOWN debit/refund.
