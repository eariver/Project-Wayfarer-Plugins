# V0.0.1 Concrete Waymark Provider Test Plan

- Status: Completed
- Date: 2026-07-29
- Source base: `16ce48dd0cdf905c5fcff5430b54459a72173e4a`
- Decision authority: ADR 0007 Owner Decision
- Candidate: `0.0.1-rc.3`

## Scope

Validate the approved Core-private Vault adapter and its JDK-only fractional balance contract
without changing the transaction engine, repository, migration, RedisEconomy, Project repository,
or Project Runtime.

Focused automated coverage:

- Vault ServicesManager discovery success/absence and close behavior;
- safe selected-provider identity and raw identity redaction;
- UUID → short-lived main-thread `OfflinePlayer` resolution;
- integer and 37.5 balance reads; long debit 25 preserving 12.5; refund restoring 37.5;
  insufficient funds; explicit failure; non-finite balance rejection; null/ambiguous result;
  provider exception; timeout-before-invocation; disable rejection; and `resolve = UNKNOWN`;
- public API/SPI `CompletionStage<BigDecimal>` shape and forbidden-type boundary;
- backward-compatible `provider-mode: vault` config and invalid provider settings;
- startup verification/recovery before provider-dependent capability availability;
- existing transaction idempotency, single debit/refund operation, UNKNOWN, reconcile, and restart
  regressions.

Run:

```text
gradlew :plugins:wayfarer-core:test
gradlew :plugins:wayfarer-core:mariaDbIntegrationTest
gradlew :plugins:wayfarer-core:redisIntegrationTest
gradlew check assemble
```

Dedicated standalone:

- Paper 1.21.11 build 132 / Java 25;
- task-only MariaDB 11.8 and Redis 8;
- fixed VaultUnlocked and RedisEconomy artifacts;
- candidate Core plus production-excluded concrete-provider probe;
- one clean provider-present run and one provider-absent fail-closed run.

Representative operations:

1. discover and identify `Vault/RedisEconomy`;
2. create a test UUID account and seed through Vault;
3. seed 37.5 and read the same fractional balance through Wayfarer;
4. Wayfarer long debit 25, observe 12.5, and perform exact idempotent replay;
5. insufficient funds;
6. direct Vault withdraw/deposit and Wayfarer cross-observation;
7. Wayfarer long refund 25 and observe both paths restored to 37.5;
8. safe health, null provider references, no raw provider object/secret;
9. clean stop;
10. provider-absent startup with provider-independent services available and Transaction/Waymark
    unavailable.

Provider exception/timeout/UNKNOWN and duplicate refund are focused automated cases. Redis outage
after Vault acceptance cannot prove the final effect and is the ADR 0007 accepted limitation; it
is not repeated as a misleading durability test. No client, stress, crash matrix, broad feature
test, or Project Runtime action is in scope.

The earlier rc.2 integer-only standalone result remains historical evidence. RC.3 reruns only the
representative fractional path and affected regressions; it does not repeat the full headless,
client, identity, crash, or stress suites.
