   cancel, insufficient funds, confirm, double-click, disconnect, and reconnect recovery.
6. Verify sanitized player/admin output and no secret, stack trace, internal exception message,

3. Inspect the Japanese navigation GUI; Loadout/Shop/Help work and Waystone is explicitly
   unavailable/non-actionable.
4. Place one Launchpad successfully and one invalid placement; confirm exactly one consumption

Stop once each representative result is unambiguous. Do not expand into stress, crash-matrix, or
