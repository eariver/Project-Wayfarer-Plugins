# V0.0.1-alpha.2 Test Plan — Persistence and Identity

- Release scope: `core`
- Requirement IDs: DATA-001, THREAD-001, CORE-004, CORE-005, TEST-002
- Test environment: Java 25; isolated MariaDB; Paper 1.21.11
- PR A Testcontainers image: `mariadb:11.8`, fixed by
  `eariver/Project_Wayfarer` `infrastructure/compose.yml`
- PR A automated task: `:plugins:wayfarer-core:mariaDbIntegrationTest`, included by `check`

PR A covers the internal pool/migration lifecycle and failure boundaries only. Durable audit,
player/item identity, repositories, and the public database contract remain PR B or later work.

## Automated

- Migrate an empty database; validate an already migrated database; preserve applied migrations.
- Prove only `wf_core_*` is created by Core and validate UUID, UTC, JSON, indexes, unique keys,
  optimistic locks, audit history, and restart recovery.
- Inject DB outage and migration failure and verify fail-closed cleanup.
- Detect and fail any main-thread JDBC access.

## Runtime

After PR A is reviewed and merged, verify empty migration, restart, DB outage, migration failure,
health transitions, cleanup, and no secret exposure on an isolated test server. Identity and
durable-audit runtime cases remain blocked on PR B. Do not run against Project databases.

## Exit

Automated and isolated results are commit-pinned; no applied migration was modified; schema and
known limitations are documented.
