# V0.0.1-alpha.2 Test Plan — Persistence and Identity

- Release scope: `core`
- Requirement IDs: DATA-001, THREAD-001, CORE-004, CORE-005, TEST-002
- Test environment: Java 25; isolated MariaDB; Paper 1.21.11

## Automated

- Migrate an empty database; validate an already migrated database; preserve applied migrations.
- Prove only `wf_core_*` is created by Core and validate UUID, UTC, JSON, indexes, unique keys,
  optimistic locks, audit history, and restart recovery.
- Inject DB outage and migration failure and verify fail-closed cleanup.
- Validate item identity failure for schema/type/UUID/owner/epoch.
- Detect and fail any main-thread JDBC access.

## Runtime

Verify empty migration, restart, DB outage, migration failure, invalid identity, owner/epoch
mismatch, persisted audit, and no secret exposure. Do not run against Project databases.

## Exit

Automated and isolated results are commit-pinned; no applied migration was modified; schema and
known limitations are documented.
