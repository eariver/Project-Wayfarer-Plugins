PR A covers the internal pool/migration lifecycle and drain ordering. PR B adds immutable V002,
durable audit, player UUID snapshots, common item identity, lifecycle/listener wiring, and the
asynchronous public item identity contract. The public database contract remains later work.

## PR A automated

- Migrate an empty database; validate an already migrated database; preserve applied migrations.
- Prove only `wf_core_*` is created by Core and validate the current V001 UUID column shape, UTC,
  JSON checks, indexes, and unique constraints.
- Inject DB outage and migration failure and verify fail-closed cleanup.
- Detect and fail any main-thread JDBC access.
- Stop new database intake independently of lifecycle callbacks, drain accepted and queued work
  before Hikari close, and distinguish drained, timed-out, and interrupted results.
- Commit two accepted operations against isolated MariaDB while disable waits, then verify both
  durable effects, health transitions, service unpublication, and graceful executor shutdown.

## PR B automated

- Upgrade a V001-only database to V002 and inspect identity PK/index/check/TIMESTAMP/ascii shape.
- Verify audit validation, 16 KiB bound, JSON parsing, secret rejection before DB, exact duplicate
  idempotency, conflicting duplicate refusal, UTC milliseconds, restart persistence, health
  failure semantics, and post-close refusal.
- Verify player UUID authority, newer-only name/server update, stale observation refusal,
  non-unique names, listener snapshot/unregister ordering, and restart recovery.
- Verify all six item claims, ordered fail-closed reasons, create-before-success, find/restart,
  mismatch handling, and mandatory identity-failure audit.
- Verify durable permission-denial audit, actor/audience snapshots, immediate command response,
  API boundary, V001 immutability, packaging, and shutdown drain ordering.
- Verify player-upsert failure audit success/failure, configured server-ID authority, and secret/
  credential/URI rejection for every caller-controlled persistent audit string with zero DB hit.
- Verify Identity `OPEN`/`CLOSING`/`CLOSED`, accepted success/failure observability, clean
  finalization, and timeout/interrupted/non-drained false-clean rejection.
- Verify ADR 0005 keeps `WayfarerDatabase` as an opaque JDK-only unavailable marker with no JDBC
  method.
