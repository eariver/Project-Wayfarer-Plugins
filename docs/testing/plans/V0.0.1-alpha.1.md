# V0.0.1-alpha.1 Test Plan — Lifecycle Foundation

- Release scope: `core`
- Requirement IDs: CORE-001, CORE-002, CORE-003, THREAD-002, TEST-001
- Test environment: Java 25; Paper 1.21.11 isolated test server

## Automated

- Typed config accepts the sanitized valid sample and rejects unknown/invalid versions.
- Missing environment secrets fail closed without secret disclosure.
- Partial initialization unwinds resources and registers no usable service.
- Enable/disable unregisters services, closes executors, and rejects late callbacks.
- Health reports config/executor/services states; permission denial is audited.
- `check`, `assemble`, and secret/packaging inspection pass.

## Runtime

Verify clean enable, clean disable, restart, invalid config, missing secret, service
registration/unregistration, `/wayfarer admin health`, permission denial, and redacted logs.
Record user observations where a client or command interaction is required.

## Exit

All applicable automated cases pass; runtime evidence is commit-pinned; no Project Runtime is
changed; failures and limitations are recorded before the next slice.
