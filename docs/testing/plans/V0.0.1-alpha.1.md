# V0.0.1-alpha.1 Test Plan — Lifecycle Foundation

- Release scope: `core`
- Requirement IDs: LIF-001, LIF-002, LIF-009–017, API-001, API-008,
  CFG-001–015, ADM-001, ADM-004, ADM-005, ADM-008, ADM-009,
  TST-001, TST-007, TST-009, TST-010, TST-015
- Test environment: Java 25; Paper 1.21.11 isolated test server

## Automated

- Typed config accepts the sanitized valid sample and rejects missing/unsupported versions,
  missing/blank IDs, invalid ranges, and invalid dependency combinations.
- Missing environment secrets fail closed without secret disclosure.
- Partial initialization unwinds resources and registers no usable service.
- Enable/disable unregisters services, closes executors, and rejects late callbacks.
- Managed executor tests cover acceptance, rejection, graceful/forced shutdown, thread naming,
  and failure observation.
- Health reports config/executor/services/lifecycle states and explicitly reports future
  dependencies as `UNKNOWN`.
- `/wayfarer admin health` covers authorization, denial event, console, redaction, unknown
  subcommands, player-safe output, and stable failure handling.
- `check`, `assemble`, configuration-cache, secret/packaging, and reproducibility inspections
  are recorded in the result.

## Runtime

Verify clean enable, clean disable, restart, invalid config, missing secret, service
registration/unregistration, `/wayfarer admin health`, permission denial, and redacted logs.
Record user observations where a client or command interaction is required. Runtime execution is
not part of the implementation PR and remains `Not started`.

## Exit

All applicable automated cases pass before the Draft PR is opened. Runtime evidence remains a
separate gate; no Project Runtime is changed, and failures/limitations are recorded before the
next slice.
