# V0.0.1-rc.1 Test Plan — Release Candidate

- Release scope: `core`
- Requirement IDs: all applicable V0.0.1 requirements
- Runtime: repository-external isolated Paper 1.21.11 / Java 25 / MariaDB / Redis / Waymark

## Procedure

- Verify release assets and SHA-256 before installation into the isolated test server.
- Back up the previous isolated runtime, apply sanitized test-only configuration, and test
  startup, migration, health, failure injection, restart, disable, reconnect, and recovery.
- Repeat representative lifecycle, identity, Redis/task, and transaction cases from all alphas.
- Record tick/thread observations, logs as short redacted excerpts, and user-observed command/client
  behavior. Do not commit runtime files or binary evidence.
- Complete the release test report, handoff package, artifact matrix, and traceability.

## Exit

All applicable cases pass or have an approved limitation; the stable source must equal this
approved RC source; Project placement and acceptance remain pending.
