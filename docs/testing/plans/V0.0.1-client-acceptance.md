## Preconditions

- The stacked PRs are reviewed and merged in order before an Owner-approved client session.
- Testing occurs in an Owner-approved isolated runtime with backups and restore instructions.
- Sanitized configuration and environment references are reviewed; no secret enters evidence.
- The candidate reports enabled health before a player joins.
- Do not execute concrete Waymark debit/refund cases while ADR 0006 is blocked.

## Stop conditions

Stop on candidate/hash mismatch, migration validation failure, Core fail-closed, unexpected
permission grant, secret disclosure, duplicate identity/effect, persistent client freeze, or an
unapproved concrete-provider requirement. Do not relax config, migration, permission, or release
gates to continue.

## Rollback boundary

Stop the isolated server using its approved procedure, preserve evidence, and restore the isolated
backup. Do not edit Flyway history, reverse V001–V003, or perform any Project Runtime rollback from
this repository. Record the incident before retrying.
